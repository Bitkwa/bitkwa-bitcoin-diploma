# Security policy

## Reporting a problem

Please report any security or privacy problem privately, do not open a public issue.

- Email: **bitkwaofficial@gmail.com** with "SECURITY" in the subject.

## What must never be committed here

API keys, tokens, passwords, wallet seeds or xpubs, and any personal data (names,
phone numbers, emails or photos of learners, instructors or partner contacts) must
never be added to this repository or to commit messages. Cohort and student records
stay in private storage, not in the public repo.
